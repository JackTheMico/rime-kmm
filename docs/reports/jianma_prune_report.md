## 2. 为什么这些码不好用

`kongmingmas.schema.yaml` 里两处字母表都不含数字 1–6：

```yaml
speller:
  alphabet: "...'7890`~@*_"        # 只有 7 8 9 0
chord_composer:
  alphabet: "qazwsxedcrfvtgbyhnujmik,ol.p;/'7890 "
```

要输入 2/3/4/5 只能走 `key_binder`：

```yaml
- { when: composing, accept: "Control+u", send: 2 }
- { when: composing, accept: "Control+i", send: 3 }
- { when: composing, accept: "Control+w", send: 4 }
- { when: composing, accept: "Control+e", send: 5 }
```

所以 `K2`（看起来）实际是「K 和弦 → Ctrl+i → 空格」三到四步，比打四码全码还慢，且打断并击节奏。

## 5. 后续：第二批已一并清理

- `我的` 同时有 `o3d=` 与 `w3d=` 两条重复变体，另有正常的 `Wd` / `WqdW`；
- `中国` = `z5g=` 与 `ZgGG`，前者要 Ctrl、后者纯并击。

这批已在同日的第二批中用 `--legacy` 删除，清单见 `jianma_prune_report_legacy.md`。

```bash
python3 tools/km_jianma_prune.py --legacy --apply
```

注意 `1`=1、`1~`=壹、`;6`=^ 这类**数字/符号直出**条目不能删，它们是唯一的输入途径，工具已内置跳过。
