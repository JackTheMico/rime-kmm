## 2. 口径

- **一次并击 = 双手同时按下**：左手出一个码元、右手出一个码元，一次最多 2 个码元（algebra 末尾 `xform/^\S{3,}$//` 会清掉 3 个以上的组合）。
- 每个码元都有左手式与右手式两种按法，例如 `R = e+t 或 y+i`、`G = d+g 或 h+k`、`Y = w+t 或 y+o`、`0 = asdf`（仅左手式）。
- 所以 `RG` = 左手 `e+t` ＋ 右手 `h+k` **同时**按下 = **1 击**，词库键正是 `RG`；「先 e+t 再 d+g」得到 `R=G=`，反而打不出 `RG`。同理 `0f`（`asdf` ＋ `j`）、`0Y`（`asdf` ＋ `y+o`）、`*c`（`r+g` ＋ `,`）都是一击。
- 单手单键 / 键+空格 同击带标记：`d=`、`=d`、`d_=`、`=_d`，都是 1 击。
- 4 码元码（`R<GG`）需要两次并击 = 2 击。
- 自动上屏 = **零延伸**（不是任何更长码的前缀）且 **唯一候选**；有延伸的码按一下空格即可上屏，不算选词。
- 「常用」按 Rime 官方语料 `essay.txt` 的单字词频排序。
- 击数由 `tools/km_chord_model.py` 模拟 `chord_composer.algebra` 算出：先用 algebra 反推每个码元的左右手按键集合，枚举「左右手各挑一种 ＋ 是否带空格」的全部组合（得到 9111 个可达码），再对词条码做分段最少击数。
