| 规则 | 条件 |

| 收益排序 | 按「词频 × 省下的击数」排，不按纯词频 |

| 长度一致 | 单字槽换单字、二字槽换二字词、三字槽换三字词 |
| 语义守恒 | `?X` 只收叠字，`@X` 三字，`*X` 四字 |
| 不动标点 | `a'`= `'`、`a,`= `,` 这类快捷槽保留 |
| 不动数字 | `1~`=壹 整族跳过 |
