## 1. 为什么会有这种码

一次并击要求**左右手各出一个码元**。而 `(sdf)`→`7`、`(wer)`→`8`、`(xcv)`→`9` 
都是**左手三键**，所以数字码元必须排在字母**前面**。词库把一批写成了「字母+数字」：

| 词 | 词库里写的 | 实际引擎收到 | 能打的写法 |
| --- | :---: | :---: | :---: |
| 的时候 | `i8` | `8i` | `8i` |
| 方式 | `F9` | `9F` | `9F` |
| 学习 | `X7` | `7X` | `7X` |

另外 `/` 之前被我误判成死码 —— `xform=(z-v-|m-G-)=/=` 这条规则的替换值是 `/`，
`z+v` 并击就能打出，`/S`、`/d`、`/Z` 全是活的。本轮已修正模型。
