## 2. 裁决规则

| 规则 | 条件 |
| --- | --- |
| 新槽优先 | `0` 族空位先拿最值钱的候选，纯赚不占地 |
| 收益排序 | 按「词频 ×（当前代价 − 2）」排，不按纯词频 |
| 残渣门槛 | `7/8/9` 族原占用者词频 < 3,000 才算残渣 |
| 置换门槛 | 新词 ≥ 3× 原占用者，且 ≥ 3,000 |
| 手动改派 | `--set 码=词` 直接照办，不走价值模型（个人习惯优先） |
| 不动标点 | `70`= `*`、`89`= `~`、`0=`= `0`、`7=`= `7` 这类直出槽保留 |
| 可回退 | 原词若仅有这一条编码则跳过，避免失去输入途径 |
