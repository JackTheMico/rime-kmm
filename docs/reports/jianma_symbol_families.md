# 空明码-宏版S 符号族简码清单

> 数据源：`kongmingmas.dict.yaml`（当前版本）。词频取自 Rime 官方 frequency 语料（转简后）。

## 核心性质：零延伸 = 打完即上屏

两码元编码分两种命运：

- **零延伸**：没有任何更长的编码以它开头，所以打完最后一个键立即上屏，**不必按空格、不弹候选**。
- **有延伸**：存在更长的编码，必须等空格或继续输入，属于「一击 + 空格」。

因此符号族（`X~`、`X'`、`7X`、`8X` …）是价值最高的档位，而字母两码（`RG`、`Ky`）大多有上千个延伸码，不享受自动上屏。
