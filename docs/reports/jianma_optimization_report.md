## 6. 部署与回滚

词库文件已自动备份为 `kongmingmas.dict.yaml.bak-<时间戳>`。
部署路径按本机实际配置调整（本例为 fcitx5 + 系统级共享目录）：

```bash
cd ~/Nextcloud/kmrime

# 1) 同步到 Rime 共享目录
sudo cp kongmingmas.dict.yaml kongmingmas_t.dict.yaml /usr/share/rime-data/

# 2) 重新部署（librime 只在主方案变化时才全量重编，故用 km_deploy 强制转一次）
sudo ./km_deploy /usr/share/rime-data ~/.local/share/fcitx5/rime
#    或者：rime_deployer --build ~/.local/share/fcitx5/rime /usr/share/rime-data

# 3) 回滚
sudo cp kongmingmas.dict.yaml.bak-<时间戳> /usr/share/rime-data/kongmingmas.dict.yaml
```

> 提示：`kongmingmas_t.dict.yaml`（繁体镜像库）已同步插入同样的简码，保持反查注释一致。
> 若只想改简体库，回滚时一并覆盖即可。

## 7. 还可继续做的事

1. **符号族简码重排**：`X~`、`X'`、`!X`、`@X` 等约 700 个槽位是零延伸码（真·一击上屏），
   其中不少被低频词占着（`I~`武当、`C~`悄然、`E~`无产阶级、`T~`解耦、`N~`男人、`U~`几个…）。
   这一族是手工设计的符号体系，改写会牵动既有肌肉记忆，建议单独评审后再动。
2. **三字词层**：目前约 1 万个三字词挤在一击槽位里互相重码，可另做一轮三字词频优化。
3. **重跑本工具**：调整 `--dead/--elite-ratio/--elite-min/--top` 即可换一套更激进或更保守的策略，
   工具是幂等的，重复执行不会重复插入。
