## 2. 留哪一条码

| 判据 | 说明 |
| --- | --- |
| 成本 | 1 = 一击即出；2 = 一击 + 空格；3 = 两次并击 |
| 默认 | 留成本最低的；同成本优先老码（备份史里最早的），再优先读音码 |
| 例外 | 若让出便宜码能换回更多收益（收益 > 该词频次 × 多出的动作），改留读音码 |
| 接收人 | 一条简码都没有、最佳路径 ≥2 击、词频 ≥ 20,000 |
| 护栏 | 符号族语义；一槽不发两次；目标只此一条；直出槽不动 |
