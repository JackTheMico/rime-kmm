# 空明码-宏版S：冗余一击槽回收与再分配

> 生成时间：2026-11-15 18:26　工具：`tools/km_jianma_reclaim.py`　词库：`kongmingmas.dict.yaml`

## 1. 结论

- **起因**：`知道` 有 `zD`、`可以` 有 `ky` 这类读音简码，词条名下再挂 `0o`/`0b` 只是省一次空格；而另有一批高频词连个一击码都没有。
- **回收 4 个槽**：多字词 4 个、单字 0 个（单字的声韵全码本来就慢，读音码 `X=` 才是主路径）。
- **再分配 4 个槽**：词语 4 个、单字 0 个；净省 **-16,289 个动作**（按语料频次折算）。
- 另有 21 个槽没找到划算的接手人（详见第 5 节）。

## 2. 判定与价值模型

**读音码** = 拼音首字母逐字拼接（大小写照抄）或方案声码串，且该码确实挂在本词名下：`如果`→`RG`、`可以`→`ky`、`知道`→`zD`、`都是`→`Ds`；单字取单键形态 `d=`（大）、`=b`（不）、`=R`（如）。

**多余一击码** = 该词名下除读音码外，其它一次并击可达的码（`0o`、`8Z`、`9e`、`dW` …）。

**成本** = 击数 +（要不要额外按空格/选词 ? 1 : 0）：零延伸唯一候选 = 打完即出，有延伸或多候选要多按一次空格。

> 摘下来的码若本身仍是更长码的前缀（如 `dW` 之于 `dWxx`），新主人照样要按空格，只算「省一个动作」；工具对此标 `prefixed`，不按「一击即出」算收益。

| 判据 | 条件 |
| --- | --- |
| 回收 | 词条有读音一击码，且名下另有一击码 |
| 不动标点/直出槽 | `K\`` 等保留码跳过 |
| 候选-词 | 无读音简码、成本 ≥ 2 动作、词频 ≥ 3,000
| 候选-字 | 无 `X=` 类读音码、成本 ≥ 2 动作、字频前 2000
| 配对 | 净收益 = 新主人收益 − 原主人代价 > 0，贪心取最大 |
| 分槽 | 词语 50%、单字 50% |
