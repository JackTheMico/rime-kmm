# 票 01 — 一击码面的物理容量与扩容上限

> 分析日期：2026-11-16　分析脚本：`one_strike_capacity_analysis.py` / `one_strike_capacity_analysis2.py`（只读，未改词库）
> 权威口径：击数/可达性由 `tools/km_chord_model.py` 判定（一次并击=左右各一码元=1击，枚举 9111 个一击可达码）。
> 补写说明：原研究代理在写报告前触发 429 限流；主会话据其留下的两份脚本重跑取数并补写本报告，数据全部来自脚本原始输出。

## ① 结论先行

1. **物理硬上限 9111 个一击码面**，当前「零延伸+唯一候选」自动上屏仅 **1377 个**（15.1%）。理论空间还很大，但**真正干净可直接用的空槽只有 5086 个**，另有 2459 个码面被「延伸码」占用（是更长码的前缀，用了会破坏长词输入）、189 个是多候选码——后两者不是免费午餐。
2. **1396 vs 1377 的差异 = 19 个死码**：`1q`/`;6`/`a7` 等含 `1`–`6` 的旧式 Ctrl 送键码，以及 `70`/`78`/`79`/`89`/`90` 等数字组合——chord 模型判定它们**一次并击打不出**。改用 chord 口径 1377 是正确选择（与 `char_onehit_report.md` §6 一致）。
3. **铁律确认仍成立**：one 码面里含 `1`–`6` 的码 = **0 个**（`km_chord_model.py` 已排除）；`X~` 数字大写族共 68 个后缀 `~` 码仍在，其中纯数字 `0~/7~/8~/9~` 只有 4 个——`X~` 作为数字大写族**保住了**，无需外借。
4. **最现实的扩容方向**（不改 algebra、不动码元系统）：符号前缀族空槽最集中——`_`(132)、`.`(112)、`*`(110)、`,`(109)、`/`(102)、`:`(100)、`?`(97)、`@`(97)、`!`(96)、`;`(94)，合计近千个干净槽；数字前缀 `0/7/8/9` 各余 80–90 个。**这些都是左右手约束下可达、词库当前未占用、非任何码前缀的干净槽**，可直接新增为一击上屏。
5. **天花板警示**：即便把 5086 个干净空槽全用上，也只是逼近「码面容量」上限；票 02 已证明**瓶颈不在槽位总数，而在零和分配**——多给词就挤掉字。扩容能缓解但无法单独解决 0.6–0.7 目标。

## ② 容量盘点矩阵

`one_press_codes()` 总数 = **9111**（硬上限，algebra + 左右手约束，不可突破）。按字符长度：1 字符 4 个、2 字符 4559 个、3 字符 4548 个。

| 分类 | 数量 | 说明 |
| :--- | ---: | :--- |
| auto — 零延伸 + 唯一候选（当前一击上屏） | **1377** | 与权威 `char_onehit_report` 的 1377 一致 |
| empty — 词库未占用的干净空槽 | **5086** | 可直接新增一击上屏，无前缀冲突 |
| ext — 被延伸码占用（是更长码的前缀） | **2459** | 用了会截断长词，需按空格/继续打 |
| zero — 零延伸但多候选 | **189** | 需选词，非自动上屏 |
| **合计** | **9111** | |

**一击上屏的三档天花板**：

| 档 | 码面数 | 含义 |
| :--- | ---: | :--- |
| 硬上限 | 9111 | algebra 决定的物理极限 |
| 保留全部现有长码 | 6652 | one 中不是任何词库码前缀的码（不破坏现有长词） |
| 只留一击码重排 | 4664 | one 内部互不为前缀的码（彻底放弃延伸） |

> 结论：在**不破坏任何现有长词输入**的前提下，一击上屏码面最多可从 1377 扩到 6652（约 4.8 倍）；但这是理论上限，实际受「词库未占用 + 语义分配」约束。

## ④ 新族候选

- **双符号码**（两字符皆符号）：one 中 179 个，如 `!!`, `!*`, `**`, `,,`, `??`, `@@`, `__` 等——**绝大多数干净空槽**，是尚未系统开发的新族。
- **大写字母 + 符号后缀**：390 个（如 `A!`–`Z~` 全组合），其中后缀 `~`/`` ` ``/`@`/`*` 族干净槽较多。
- **`X~` 数字大写族**：68 个后缀 `~` 码仍在，其中纯数字 `0~/7~/8~/9~` 只有 4 个。按项目铁律**永不外借**——本报告复核后确认无需动它。
- **含 `1`–`6` 的码**：one 中 0 个，确认不可便宜使用（只能 Ctrl 送键）。

## ⑤ 方法、铁律复核与未确认项

- **方法**：`one_strike_capacity_analysis.py` 逐行流式读 `kongmingmas.dict.yaml`（1661030 行），构建「一击可达码集」（`km_chord_model.one_press_codes()`）、「所有词库码集」、「码前缀集」（严格 pref_all），做四象限分类；`analysis2.py` 修正带空格码的族归类并统计 1396/1377 差异。运行命令见脚本头部。
- **复现校验**：复现出 `≤3码元零延伸唯一=1396`、`one可达零延伸唯一=1377`，与 `jianma_reference.md`、`char_onehit_report.md` §6 完全一致，口径正确。
- **铁律复核**：`X~` 不可外借 ✅、`1`–`6` 不可用 ✅、`/` 可达 ✅（不是死码）、`'` 右手单键并击 ✅（已计入 RIGHT_KEYS）。
- **未确认 / 边界**：
  - 「其他族 2704 个空槽」是纯大写组合码（AA/AB…），语义上无数字大写族那样的既定含义，可自由分配但需设计映射规则（如按拼音首字母 → 大写组合），属票 05 的取舍问题。
  - 5086 个干净空槽是「可达且非前缀」的码面数，不等于「都能挂高频词」——挂词还需词表与语义分配（票 02 的零和冲突面）。
  - 双符号码/大写+符号码虽在 one 可达集内，但实际并击手感与记忆成本未评估。
