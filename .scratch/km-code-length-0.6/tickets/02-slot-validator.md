# 02 — 空槽校验器：杜绝伪空槽

**What to build:** 维护者在往空槽挂词之前，能确定目标码真的"干净"。交付一个只读校验工具：输入候选码，逐个判定四项——并击可达（以权威击数模型为唯一判据）、词库未占用、不是任何现有码的前缀、挂词后为零延伸唯一候选；输出 certified 干净空槽清单，并把 `@k` 这类"看着空、其实是长词前缀"的伪空槽明确剔除。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 对 `< ; ! @ ?` 五符号族各输出可达码数、已占数、干净空槽数，与已验证脚本（research/check_symbol_slots.py、verify_slot_count.py）的结果一致
- [ ] 伪空槽（如 `@k` 是"可以说"的前缀）被判定为不可用并给出原因，不会被当成空槽放行
- [ ] 可达性判定直接调用权威击数模型，不靠肉眼数码元；含 1–6 的码被排除
- [ ] `X~` 数字大写族被标记为受保护、不进入可挂词清单
- [ ] 清单条目无重复（计数已去重核实）
- [ ] 工具只读，不改词库
