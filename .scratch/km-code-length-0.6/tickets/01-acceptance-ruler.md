# 01 — 验收尺子：码长四数聚合工具

**What to build:** 打字用户能看到自己改动到底有没有让码长变短，而不是凭感觉。交付一个只读指标工具：喂给它一段文本和词库，输出四个数——理论码长、实测码长、打词率、选重率；理论线与实测线独立判定达标，不互相冒充。这个工具是后续所有票端到端断言的唯一入口，计击口径只在它一处实现。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 对当前词库运行能输出四个数，理论码长与实测码长是两个独立结果、各自有达标判定（理论 ≤0.7 / 实测 ≤0.8）
- [ ] 同一段文本 + 同一份词库重复运行，四个数完全一致（可复现、可对比改动前后）
- [ ] 严格计击：选重、空格确认、预测上屏均计入击数，账面码长不会因机制而虚假下降
- [ ] 输出同时含打词率与选重率，能识别"靠极端打法凑低码长"
- [ ] 理论码长按码表算每个字词的最短击数得出，与用户练习程度无关
- [ ] 工具只读，运行前后词库字节不变
