# 票 05 — 一击槽位在「单字」与「词」之间如何取舍

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

一击码位零和：给词就挤掉字。而降 `c1` 要单字全一击、降 `cw` 要词一击，两者抢同一批槽。需用户拍板：

1. 当前前 100 字 100% 一击、前 1500 字仅 73.1% 一次并击出——是否接受牺牲部分低频单字的一击性，换取高频词的 ≤2 码元覆盖？
2. 划一条线：单字一击覆盖到前 N 字（N=500? 1000? 1500?）就不再让位给词？
3. `X~` 族「永不外借」是否在本轮继续生效，还是为降码长解禁？

依赖票 01（容量上限）与票 02（词覆盖缺口）的数据。

## Answer

用户拍板（2026-11-16）——

1. **单字一击率守住前 1500 现状**：不动现有 529 个单字一击槽中的高频部分，c1=1.269 作为预算基线不允许因让槽而恶化。收益：守住 K 模型的 `c1` 半边，不打词率门槛上抬。
2. **5086 增量空槽优先挂高频二字词**：走「增量扩容」而非「存量重排」路线。用符号前缀族（`_`/`*`/`,`/`.` 等每族 89–132 槽）、双符号码（179）、大写+符号（390）等干净空槽，优先补二字词一击覆盖，把词频加权覆盖率从当前前 1000 的 84.4%、前 5000 的 61.9% 往上推。目标区间：覆盖率先破 K=0.7 自洽线 83%（已近达成），K=0.6 的 92% 需覆盖到前 2000–3000 词。
3. **`X~` 维持永不外借**：票 01 已证实不动它即可达标，保住数字大写输入。

**能力边界（如实记录，来自票 02 §④/§③.3）**：增量空槽是「可达且非前缀」的码面，但挂词仍需语义分配；前 1000 有 221 个二字词未一击、前 5000 有 2365 个未一击，符号前缀族近千槽只能覆盖其中一部分。靠增量扩槽能破 K=0.7，但 K=0.6 仍需票 06 的打词率策略与长词简码配合，不能单靠本票。

**对下游票的约束**：
- 票 06 打词率路径以「增量覆盖到 K=0.7 线」为起点，重点在如何让实际 p≥83%。
- 票 07 同步策略按「只动 `kongmingmas`、增量挂词」的实施范围来定。
