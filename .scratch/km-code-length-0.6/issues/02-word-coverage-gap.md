# 票 02 — 高频词的一击覆盖率缺口

## Question

模型要求「词平均码元数 ≤2」才能跌破 1 击/字。回答：

1. 取一份高频词表（优先项目现有语料/词库内建词频，或 Rime `essay.txt` 派生），统计前 1000 / 5000 / 2 万高频词里，**当前已有 ≤2 码元简码**的比例；重点看二字词。
2. 缺口有多大？要把「二字词一击覆盖率」提到多少，才能支撑打词率 `p` 达到 74%（c1=1.269 时 K=0.7）或 87%（K=0.6）？
3. 一击槽位是零和的：每多给一个词，就挤掉一个候选字/词。给出「为词扩容」与「保住单字一击率」之间的量化冲突面。

这决定「一词一击扩容」到底值不值得做、能做到什么程度。

## Answer

二字词一击覆盖率（词数口径）前 1000/5000/2 万 = **71.0%/32.9%/11.1%**，词频加权 = 84.4%/61.9%/48.9%；二字词平均码元数 2.58/3.34/3.77，普遍 >2，结构性达不到「词均≤2」硬前提。要自洽支撑目标，覆盖率需 ≥83.1%（K=0.7）/ ≥91.9%（K=0.6）；若坚持外部研究的低打词率门槛（p=74/87%），则需 ~100%。零和冲突：每让 100 槽给词，单字一击率掉 1.7–6.7 pp，净效应接近相抵。详见 `research/word-coverage-gap.md`。
