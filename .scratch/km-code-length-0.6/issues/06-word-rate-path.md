## Question

模型显示打词率 `p` 是杠杆之一（c1=1.269 时要 K=0.7 需 p≥74%）。但你已开放三类相关手段，需选组合：

1. **词库侧**：扩长词/短语简码（成本低） vs 提升二字词一击覆盖（需票 05 让槽）。
2. **引导侧**：通过 `dazitui` 训练/提示引导用户多打词——这种做法接受吗？会改变用户习惯，代价是学习成本。
3. **机制侧**：顶功/联想/整句能否替用户「自动打词」，从而抬高有效 `p`？

三者如何组合、优先级如何。依赖票 02（词覆盖缺口）与票 03（机制可行性）。
